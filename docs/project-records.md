# 개발 기록

기존 Issue-first, Project 상태 전이·종료 동기화, 승인 증빙, Blueprint 운영 규약은 폐지했다. 개발 방식은 [AGENTS.md](../AGENTS.md)를 따른다.

작은 작업은 커밋 메시지 또는 PR 설명이면 충분하다. Issue와 ADR은 별도 추적·중요한 장기 결정에 필요할 때만 쓰며, GitHub/Project 접근이 없어도 로컬 개발을 막지 않는다. 다른 문서의 예전 Issue·승인 절차 언급은 필수 절차가 아니다.

기존 Issue·PR·Project·ADR은 이력으로 보존한다. 외부 Project 자동화 설정은 변경하지 않았으며 그 상태를 맞추는 작업을 Agent에게 요구하지 않는다.
